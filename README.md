# Оно тебе надо — аукцион вещей, в которые никто не верил

Проектная работа: вёрстка страницы аукциона «Оно тебе надо».

## Описание

Аукцион вещей, в которые никто не верил. Проект состоит из нескольких секций:

- шапка с меню, логотипом и адресом;
- обложка с заголовком и кнопкой «Сделать ставку»;
- секция с карточками лотов (фильм, книга, картина);
- секция «Об аукционе» с логотипом и описанием;
- подвал с адресом, меню и ссылками на соцсети.

## Технологии

- HTML5
- CSS3
- Шрифт Raleway
